# AIのべりすと ユーザースクリプト刷新 引き継ぎメモ

2026-10-09 作成。新しいチャットで刷新作業を始めるときに最初に読むメモ。

## このフォルダについて

`ainovel-before-renewal/` は、刷新前にViolentmonkeyで使っていたAIのべりすと用スクリプトの控え（2026-10-09のバックアップから）。刷新で何か壊れたときはここから戻せる。

リポジトリ直下にある `authorsnote-*` や `petitbot-*` などは、このバックアップには入っていなかった古いもの。今は使っていない可能性が高い。

## 作業のルール

- スマホで作業しているので、コードの修正は差分ではなく全文で出す。
- 頼んでいないボタンや機能を勝手に足さない。
- 配布はこのリポジトリに置いて、Violentmonkeyの「URLからインストール」で入れる。
  URLの形：`https://raw.githubusercontent.com/YUUKI490/userscripts/main/ファイル名.user.js`
- Violentmonkeyは `@name` と `@namespace` が同じなら上書き更新になる。

## スクリプト同士のつながり

- 右スワイプ式ツールパレット（`#ainovel-tool-palette`）に、ほかのスクリプトがボタン（`.ainovel-tool-palette-button`）を足す形。
- 洗脳状態一覧は localStorage の `ainovel_brainwash_states`（`名前=状態` を1行ずつ）。清書スクリプトが書き、QuickPasteとキャラ画像が読む。
- QuickPaste は `#retryoptions` に「キャラ一覧」（`#qp_show_btn`）と「読込」（`#qp_load_btn`）を足す。入力パネルが開いているとき（`#aib_overlay.aib-open`）はパネルのユーザー欄 `#aib_user` の最後に貼り、閉じているときは `#chat_field` に貼る。
- 入力パネルの「QP辞書」「QP読込」は、QuickPasteの上の2つのボタンを代わりに押しているだけ。

## のべりすと画面（novel2・チャットUI）で調べたこと

**本文ブロック**
- 本文欄は `#data_container`。中に `.data_block` が並ぶ（`data-index` は上からの番号）。
- 種類はヘッダーの `.category[data-category]`（`plaintext` / `user` / `assistant`）と、本文の `.data_edit` のクラス（`plaintext` / `user` / `assistant`）でわかる。
- ブロック右上の「＋」（`.icon_plus`）で作れるのはテキストブロックだけ。ラベルを押しても種類は変わらない。
- サイト内部の関数 `createDataBlockElement(0, [{ cat: 'User' か 'Assistant', text: '...' }])` で種類を指定してブロックを作れる（cat は大文字始まり。plaintext と thinking は小文字）。
- 作ったあとは、サイトと同じく `AttachListeners()` → `ApplyIconRules()` → `VisualChange()` → `CopyContent()` → `syncDOMToStorageDebounced(null)` を呼ぶ。保存は画面のブロックを読み取る方式なので、これで残る。
- 最後がAIブロックで書き出しが入っている状態で「続ける」を押すと、その書き出しの続きから生成される（確認済み）。

**入力・ボタン**
- 指示の入力欄：`#chat_field`
- 生成ボタン「続ける」：`#getcontinuation_chat`
- 空欄の送信を許可：`#chat_sendblank`
- リトライ等のボタン列：`#retryoptions`（`#undo` `#redo` など）

**脚注・プチボット・キャラブック**（以前調べたもの）
- 脚注欄：`textarea#authorsnote`（最大6000字、送信スイッチ `#authorsnote_send_check`）
- プチボット：各 `#petitbot_prompt0〜`、出力先 `#petitbot_output0〜`、専用欄のAI出力 `textarea#petitbot_output_assistant`
- キャラブック本文：`textarea#wientryN`、タグ：`#witagN`、無効チェック：`#text-witag-invalidN`（チェックあり＝無効。切り替えると change で `WriteWIIntoStorage()` が呼ばれて保存）

## 入力パネル（AIブロック追加 v2.0）で決めたこと

- ツールパレットの「➕ ユーザー＋AI追加」を押すとパネルが開く（押しただけではブロックを作らない）。
- 上がユーザー欄、真ん中に「QP辞書」「QP読込」「続ける」、下がAI欄、一番下にテンプレ「1」「2」「3」と「⚙」。
- 「続ける」：ユーザーブロック＋AIブロックを作る → パネルを閉じる → 0.5秒待ってのべりすとの「続ける」を押す。両方の欄は空に戻す。
- 「×」で閉じたら何も作らない（書きかけは残る）。
- テンプレ1〜3を押すと、AI欄の中身をそのテンプレに置き換える。「⚙」で3つの中身を書いて保存（localStorage `ainovel_aiblock_templates`）。
